# Support

## Getting help

- **Docs first:** `docs/index.md` is the map; `docs/quickstart.md` gets
  you through your first review in five minutes; `docs/faq.md` answers
  the questions that come up most.
- **Bugs and feature requests:** open an issue on GitHub —
  https://github.com/BidyutRoy2/hunkgate/issues — using the bug or
  feature template.
- **Questions:** open a Discussion on the repo, or ask in an issue
  labelled `question`.

## Before you report a bug

1. Run `hunkgate doctor` and paste its output.
2. Run the failing command with the smallest diff that reproduces it.
3. Redact any real secrets from the diff before pasting it — the issue
   tracker is public.

## Response times

This is a one-maintainer project. Issues are triaged within a week;
security reports (see `SECURITY.md`) are acknowledged within 7 days.
